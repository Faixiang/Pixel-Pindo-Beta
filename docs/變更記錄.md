## 階段 2.5 · 左側可拉出卡片抽屜

**新增**
- `.drawer` 半常駐卡片抽屜（330 × 878px，露出 44px 拉柄）
- `createDrawer()` 通用控制器（支援 left/right/bottom 三方向）

**修正**
1. **拉柄跑到螢幕外**（x=1829 > 視窗 1600）：拉柄原本在卡片左側，收合時 `translateX(calc(-100% + 44px))` 把拉柄推出。改為拉柄在卡片**右側**，收起時露出的就是拉柄本身
2. **拖曳無反應**：`pointermove`/`pointerup` 只綁在拉柄上，指標移出即斷 → 改綁 `window`
3. 抽屜高度：滿版 → `min(62vh, 540px)` → `+20%` 648px → `+20%` 778px → `+20%` 900px → 滿版 976px → `-10%` 878px（最終）
4. 寬度：300px → `+10%` 330px（最終）

## 階段 5 · 物理邊界修正

**問題**：豆子掉出可視框外

**根因**（兩層）
1. `resize()` 順序錯誤：先更新 W/H → 重建牆體 → 才夾回豆子，豆子被新牆彈飛
2. canvas CSS 尺寸大於容器可用高度，畫到框外

**修正**
1. `resize()` 改為：凍結豆子（static）→ 更新 W/H → 夾回 → 重建牆 → 再夾 → 解除 static
2. `clampBodyInside()` 邊距改 `R + 2`，每次都清速度與角速度
3. 牆體加厚 `max(60, R×4)`、回彈 0、底部摩擦 0.6、左右牆高 `H × 4`
4. `tick()` 每幀兜底：越界豆子立即夾回
5. 統一豆盒容器：抽出時搬移 `#boxWrap` 整包（原本搬 canvas 到 `.box-float-wrap`，CSS 規則衝突）
6. 量測改用 `clientWidth/clientHeight - 2`（扣邊框），不用 `getBoundingClientRect()`
7. 清理重複 CSS：`.box-wrap` 原本 3 份、`#boxCanvas` 2 份，合併為各 1 份

## 階段 6 · 浮窗可縮放 + 依豆量限制最小尺寸

**新增**
- `updateFloatMinSize()`：依豆子數量計算浮窗最小尺寸
- `startFloatResizeWatch()`：`ResizeObserver` 監聽浮窗尺寸變化
- `physics-box.js` 新增 `clampAll()` 公開 API

**最小尺寸公式**
```
cols = ceil(sqrt(n × 2.2))
rows = ceil(n / cols)
豆盒寬 = cols × 豆徑 × 1.15
豆盒高 = max(rows × 豆徑 × 1.15 + 豆徑×2, 豆徑×5)
浮窗 = 豆盒 + (24, 95)
下限 = max(280, 240)
```

**修正**
- `physics-box.js` 有兩份重複的 `buildWalls()` 定義 → 刪除舊版
- 縮小瞬間豆子來不及夾回 → resize 後呼叫 `box.clampAll()`

## 階段 8 · 圖片區域裁切（兩次方案演進）

**修正（裁切座標記錄）**
1. 圖片庫原本沒存 `crop` → 新增欄位並在套用時寫入
2. 座標換算錯誤：原本用 `sel.x0 / sel.w`（選取寬度）計算比例 → 改用**框選前的網格尺寸** `lastGridW/lastGridH`
