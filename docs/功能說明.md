# 功能說明

本文件逐一說明各功能的操作方式與內部行為。

---

## 一、上傳與圖片處理

### 上傳
- 支援拖曳到左側抽屜的虛線區，或點擊選擇檔案
- 上傳後**直接像素化到釘板**（不再彈出裁切視窗）
- 同時自動存入右側「圖片庫」

### 內建示範
- 左側抽屜「使用內建示範圖案（32×32 愛心）」
- 不需上傳即可體驗完整流程

### 尺寸設定
- 寬／高：8–128（預設 40×40）
- 預設按鈕：29×29、40×40、58×58、80×80、104×104
- 修改後按「生成圖案與色號清單」重新生成

### 像素化原理
1. 建立目標尺寸的離屏 canvas
2. 透明底先鋪白（避免透明像素變黑）
3. 高品質降採樣繪入圖片
4. 逐格讀取 RGB
5. 以 **redmean 加權色差** 對映到 192 色卡中最近色

## 二、釘板

### 縮放
| 操作 | 行為 |
|------|------|
| 滾輪 | 以游標位置為錨點縮放（×1.15 / 次） |
| 滑桿 | 0.5× – 8×，步進 0.25 |
| `+` / `−` | 以視口中心縮放 |
| `⊞` | 回到自動適應視窗 |

### 平移
- 在釘板上按住拖曳（位移 >5px 判定為平移）
- 平移範圍有鉗制，圖案不會完全移出視野

### 自動適應
- 預設開啟：依容器可用空間自動計算倍率
- 手動縮放後以手動為準，按 `⊞` 可還原
- 視窗或容器尺寸變化時自動重算（`ResizeObserver`）

### 框選編輯
1. 點釘板標題列右側 **`✎ 編輯`**
2. 進入框選模式：框外變暗、預設全選
3. 在釘板上按住拖曳選取範圍
4. 底部工具列顯示 `20×20 格（第21行、第21列起）`
5. 按「套用」→ 依該範圍重新生成
6. 按「取消」或 `✕ 結束編輯` 退出

**座標換算**：框選範圍會依「框選前的網格尺寸」比例換算回原圖像素座標，確保取到正確區域。

### 放置與收回
- **放置**：從豆盒抓豆拖到格子，鬆手即吸附
- **收回**：點擊已放的豆
- **異色提示**：放錯色會閃黃框 900ms 並加紅圈標記

### 顯示選項
- `顯示目標底圖`：半透明幽靈色顯示目標顏色（透明度 0.22）
- 格線：每格細線、每 5 格加粗
- 凸釘：空格中心小圓點

## 三、色號清單

### 內容
每列顯示：色塊、色號、色名、需求數、已放數、剩餘數

### 互動
- 點選任一列 → 該色號成為「目前選取色」，豆盒倒豆即倒此色
- 完成的顏色（剩餘 0）會變淡
- 區塊標題右側徽章顯示「仍有剩餘需求的顏色數」

### 統計規則
- **需求** = 目標圖案中該色的格子數
- **已放** = 實際放上釘板的該色數量（含放錯位置）
- **剩餘** = 需求 − 放對數（異色放置不抵扣）
- **完成度** = 放對總數 ÷ 需求總數

### 匯出
「匯出購豆清單 JSON」包含：
```json
{
  "size": { "width": 40, "height": 40 },
  "progress": { "demandTotal": 1600, "placedTotal": 0, "correctTotal": 0, "wrongTotal": 0, "remaining": 1600, "percent": 0 },
  "colors": [{ "code": "A08", "name": "紅08", "hex": "#DB2480", "demand": 400, "placed": 0, "remaining": 400 }]
}
```

## 四、物理豆盒

### 開啟
- 底部半常駐抽屜，點拉柄或向上拖曳展開（60vh × 0.75 = 45vh 高）

### 倒豆
- 點「倒豆」倒入目前選取色 20 顆
- 豆子從盒頂落入，受重力堆疊
- 上限 120 顆

### 翻動
- 點「翻動」給所有豆子隨機向上/側向速度，便於翻找

### 抓豆
- 在豆盒上按住任一豆子拖曳
- 拖到釘板格子鬆手即放置
- 未放到有效格子則自動回盒

### 抽出成浮窗
1. 點拉柄上的 **`⇱ 抽出`**
2. 豆盒成為右上角浮動小窗，底部抽屜自動收起
3. 浮窗可拖曳標題列移動、可拖曳右下角調整大小
4. 點 **`⇲ 收回`** 或浮窗 `✕` 回到抽屜

### 浮窗最小尺寸
依豆子數量動態計算（單層平鋪為安全下限）：

| 豆子數 | 浮窗最小 |
|--------|----------|
| 0–20 | 280 × 240 |
| 50 | 353 × 297 |
| 100 | 473 × 357 |
| 120 | 533 × 387 |

公式：
```
cols = ceil(sqrt(n × 2.2))
rows = ceil(n / cols)
豆盒寬 = cols × 豆徑 × 1.15
豆盒高 = rows × 豆徑 × 1.15 + 豆徑×2
浮窗 = 豆盒 + (24, 95)
```

### 物理穩定性機制
1. `resize()` 先凍結所有豆子（設 static）再夾回新邊界
2. 重建牆體後再夾一次
3. 每幀兜底檢查：任何越界豆子立即夾回並清零速度
4. 牆體厚度 `max(60, R×4)`、回彈 0、底部摩擦 0.6

## 五、圖片庫

### 自動保存
- 每次上傳自動存入瀏覽器 IndexedDB（資料庫名 `pixel-pindo`，store `images`）
- 記錄結構：
```js
{
  id, name, size, type, blob,
  gridW, gridH,
  crop: { sx, sy, sw, sh } | null,
  createdAt
}
```

### 載入
- 點縮圖或「載入」按鈕
- 還原：原圖、裁切區域、網格尺寸
- 提示「（包含裁切區域）」

### 複製
- 產生新項目，名稱加「(複本)」
- 一併複製 blob、裁切區域、網格尺寸
- 可用於同一張圖做不同尺寸的作品

### 刪除
- 單筆「刪除」
- 「清空全部」需確認對話框

### 顯示資訊
`檔案大小 · 上傳時間（MM/DD HH:mm）· 已裁切（若有）`

## 六、背景與主題

### 宇宙光暈
固定層 `.cosmic`，三道 radial-gradient（紫 78%/-12%、青 8%/6%、粉 62%/116%）

### 網格動畫
- Canvas `#bgGrid` 繪製 80px 格子
- 20% 格子隨機填色並顯示 HEX
- 整片以 45° 連續上飄（速度 0.9px/幀，30fps）
- 每 5 秒更換 seed

### 主題切換
- 右下角浮鈕（🌙 / ☀️）
- 深色：`--bg: #0A0B1A`
- 淺色：`--bg: #E4E8F0`，卡片改白玻璃
- 偏好存 `localStorage` 的 `bead-theme`

## 七、鍵盤與無障礙

| 按鍵 | 行為 |
|------|------|
| `Esc` | 收起所有抽屜 |
| `Enter` / `Space`（聚焦拉柄時） | 切換抽屜 |

- 抽屜拉柄有 `role="button"`、`tabindex="0"`、`aria-label`
- 抽屜開合時同步 `aria-hidden`
